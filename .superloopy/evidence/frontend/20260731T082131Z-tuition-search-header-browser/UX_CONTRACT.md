# UX Contract

## Goal

- Promote student search into the high-frequency position in the tuition month header.
- Make the search field immediately recognizable with a green border band and search icon.
- Reduce the monthly creation action to a compact icon button without removing it.
- Preserve the existing student filtering behavior and clear-search workflow.

## Responsive Behavior

- Wide desktop: year controls, search, and compact month creation remain on one row.
- Compact desktop/tablet: search moves to a full-width second row inside the month header.
- Mobile: year controls and compact creation remain on the first row; search stays full width.

## States

- Search idle: green 2px border and visible placeholder.
- Search focused: darker green border with a restrained focus ring.
- Search populated: clear button becomes available.
- Next-month action: 42px icon button with title and accessible label.
